# prebuilt —— 注入运行时的发布版二进制

| 文件 | 是什么 |
|---|---|
| `render_hook.dll` | 注入进游戏的运行时（世界状态推送、语义命令、JASS 通道、画板、输入、气泡、血条…… 全部核心能力） |
| `war3_launch.exe` | 多开启动器：起游戏、注入 DLL、开局 |
| `war3_ui_command.exe` | 命令行：给运行中的游戏发一个运行时动作 |
| `manifest.json` | 版本号和每个文件的 SHA256 |

运行时源码不开源。你不用手动处理这些文件：双击仓库根目录的 `start.bat`，它会按 `manifest.json` 核对后复制到 `bin\`，
以后仓库更新了二进制，再双击一次就同步（游戏开着时 DLL 被占用，先关掉游戏）。

外部程序和运行时之间的全部契约（共享内存布局、操作码、回执）见 [W3P 协议](../docs/W3P_PROTOCOL_ZH.md)。

只支持魔兽争霸 III **1.27a（Game.dll 1.27.0.52240）**，只用于你自己合法拥有的客户端、本机 / 局域网 / 自建游戏，
不得用于 Battle.net 或任何有反作弊的服务器。注入类 DLL 可能被杀毒软件误报；被隔离时把仓库目录加进杀毒软件的排除列表。
